# Your skill overrides

Markdown files here are loaded by the `stanley` router after the plugin's own skills, in every run, local or cloud (because the vault is what both can reach). Use them for rules that are about you, not about everyone:

- `write.md` — "always end with an open question", "never mention customers by name"
- `scout.md` — "weight posts about hiring higher", "skip anything about crypto"
- `voice-comments.md` — extra comment exemplars

Keep each file short. Anything that would help everyone belongs in a PR to the plugin instead (`/open-stanley:learn` can draft it).
