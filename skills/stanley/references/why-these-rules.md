# Why these rules (the failure log they come from)

Observed over 35 days of a paid "AI head of content" running for one founder, Aug–Sep 2026, plus the same failures reported publicly by another founder (AiSDR's CEO, 4 Sep 2026) using the same category of tool.

| Rule | What happened without it |
|---|---|
| Human-origin material first | Day 1: eight drafts, one usable. The usable one was the only one built on a source the user then verified himself. The other founder: "fake stories that fit the viral pattern but have nothing to do with my life." |
| Edit, don't generate | "Sounds like AI" was said seven times. The comments the user actually posted were his 1–2 sentence rewrites of 100-word drafts. |
| No receipt, no claim | Drafts cited 2024–25 papers as new in 2026; one draft said "recent literature shows" with nothing behind it; the tool later admitted a subagent had invented the line. |
| Never re-say | Draft 1 was "almost a copycat" of an existing post; the same three LinkedIn posts were suggested twice four days apart; the user was told to comment on his own posts four times; an old draft resurfaced the day after it was published. |
| Audit before the human sees it | The user was the linter: "too much text", "first sentence not easy to read for non-tech founders", "reads like a research paper", "remove the last two sentences". |
| The edit is the training signal | The tool replied "these edits make the pattern very clear… calibrating" and produced the same style the next day. The other founder: "it keeps happening despite recurring feedback." |
| Run records | 10pm scan on 13 Aug and 10am scan on 15 Aug never fired; LinkedIn was skipped in most early scans while the message said "both platforms"; "LinkedIn posts coming in a separate message" never came. |
| Capability probe | Custom MCP (the user's own meeting note-taker) could not be connected at all; the fix offered was "paste transcripts into the chat". |
| Browser over API | X API cannot reply to or quote accounts that haven't mentioned you, so the "comment on X" job collapsed into "paste this yourself"; LinkedIn search hit a monthly quota twice. |
